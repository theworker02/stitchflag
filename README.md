# stitchflag

Stitch lightweight flag statistics from stdin samples.

**Site:** https://theworker02.github.io/stitchflag/

## Install / run

```bash
git clone https://github.com/theworker02/stitchflag.git
cd stitchflag
node src/cli.js
node --test
```
